Ekspor pesanan hari ini

Unduh laporan pesanan hari ini dalam format CSV yang dapat dibuka di Microsoft Excel. Laporan mencakup kode pesanan, pelanggan, WhatsApp, alamat, produk, subtotal, ongkir, total, status, dan catatan admin.

Ekspor akan mengambil data hari ini dari API.

WhatsApp pelanggan

Ketika admin menerima atau menolak pesanan, sistem menyiapkan pesan sesuai keputusan dan membuka WhatsApp pelanggan. Admin tetap perlu menekan tombol Kirim di WhatsApp.

Reset data pesanan hari ini

Reset akan menghapus data pesanan bertanggal hari ini dari Turso dan menghapus file bukti transfer terkait dari Cloudinary. Tindakan ini tidak bisa dibatalkan. Sistem akan meminta ekspor berhasil terlebih dahulu dan konfirmasi tambahan sebelum reset.

Wajib unduh laporan hari ini terlebih dahulu.
Catatan: fitur reset hanya benar-benar menghapus data jika endpoint /api/admin-reset di server menerapkan penghapusan Turso dan Cloudinary. Jangan membuka halaman admin untuk umum sebelum menambahkan autentikasi.
